# Imagegen Frontend Web

Use this skill when the requested output is a generated website mockup or visual reference image, not production code.

## Web comp brief

Before generating, infer or state:

- Surface: home, Art index, Comics index, Games index, detail page, hero, navigation, gallery.
- Audience: visitor, reader, player, collaborator.
- Design language: pixel-art expressive, editorial comic archive, game cabinet, art gallery, studio identity.
- Device: desktop, mobile, or responsive set.
- Fidelity: rough direction, polished comp, or implementation reference.

## Prompt structure

Include:

- Layout composition.
- Typography direction.
- Palette and contrast.
- Actual content blocks expected on the page.
- Asset treatment: screenshots, comic panels, pixel icons, video stills, thumbnails.
- Interaction hints shown visually, such as hover state or active nav.
- Anti-patterns to avoid.

## FireKS defaults

- Use vivid but controlled color.
- Keep pixel identity visible without making everything noisy.
- Favor real content frames and gallery/game/comic artifacts over generic abstract decoration.
- Avoid corporate SaaS cards, AI-purple gradients, random glass panels, and placeholder stock-photo vibes.

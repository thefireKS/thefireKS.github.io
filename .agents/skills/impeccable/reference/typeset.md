# Typeset

Fix typography.

Check:

- Heading scale and hierarchy.
- Line length around 65-75ch for prose.
- Mobile wrapping and long words.
- Font count and weight contrast.
- Use of existing brand fonts.
- `text-wrap: balance` for headings and `text-wrap: pretty` for prose when appropriate.

For this project, treat Pixeloid as a brand asset unless the user asks for a new identity direction.

# Brand Register

Use when design is part of the product: brand sites, landing pages, marketing surfaces, campaign pages, portfolios, content hubs, art/comics/games pages, about pages.

## Standard

Brand work should have a point of view. A visitor should feel that the page belongs to this project, not to the average generated landing page.

## FireKS stance

- Preserve the pixel/creative identity.
- Let art, comics, game imagery, video, thumbnails, and iconography carry the page when available.
- Avoid SaaS polish that sands off personality.
- Choose a named aesthetic lane before designing: arcade cabinet, comic archive, artist studio wall, game cartridge shelf, experimental personal site, or another specific reference.

## Typography

- Pick fonts by brand voice, not by trend.
- Existing Pixeloid fonts are identity assets. Preserve them unless the task explicitly calls for a type rethink.
- Use scale and weight contrast. Avoid repeated tiny uppercase labels as section grammar.
- Use `text-wrap: balance` for h1-h3 where supported.

## Color

- Existing theme variables are committed brand material.
- Prefer controlled contrast over one-note saturation.
- Use committed color when a section needs personality, but keep reading surfaces legible.
- Do not default to beige, generic purple-blue AI gradients, or corporate slate.

## Layout

- Use asymmetry, overlap, and rhythm when they clarify the creative identity.
- Cards are acceptable for repeated content like art, comics, games, and chapters, but avoid card-in-card layouts.
- For content grids, prefer responsive CSS Grid with stable min/max tracks.

## Imagery

Brand surfaces should use real project assets when available. Text-only is acceptable only when typography itself is the visual concept.

## Motion

Motion should feel like interface personality or content reveal, not decoration. Include reduced-motion alternatives.

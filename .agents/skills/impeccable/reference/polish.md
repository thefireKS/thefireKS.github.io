# Polish

Final pass before shipping a frontend surface.

Check:

- Alignment, spacing rhythm, and optical balance.
- Typography hierarchy and line wrapping.
- Contrast and theme consistency.
- Hover, focus, active, disabled, loading, and empty states where relevant.
- Mobile and desktop behavior.
- Reduced-motion handling.
- Copy specificity and button labels.
- No obvious AI design tells.

Make small, high-confidence fixes and verify with build or browser inspection when possible.

# Layout

Improve spacing, grid, rhythm, hierarchy, and responsive structure.

Prefer:

- CSS Grid for 2D repeated content.
- Flexbox for 1D alignment.
- Stable min/max tracks such as `repeat(auto-fit, minmax(...))`.
- Container constraints and readable line lengths.
- Intentional asymmetry when it supports the brand.

Avoid:

- Horizontal overflow.
- Fixed pixel widths that break mobile.
- Cards nested inside cards.
- Equal-height content when natural rhythm reads better.

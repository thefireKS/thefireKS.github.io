# Product Register

Use when design serves a task: admin UI, settings, dashboards, forms, editors, authenticated tools, and compact workflows.

## Standard

The tool should disappear into the task. Familiarity is a feature when users are trying to get work done.

## Rules

- Prefer one well-tuned type family.
- Use fixed rem scales for dense UI.
- Keep accent color for actions, selection, and state.
- Every component needs default, hover, focus, active, disabled, loading, and error where relevant.
- Use skeleton loading over arbitrary spinners.
- Empty states should teach the next action.
- Motion conveys state, feedback, loading, or reveal.

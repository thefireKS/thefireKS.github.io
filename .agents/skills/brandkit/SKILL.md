# Brandkit

Use this skill when the deliverable is a brand direction or visual identity board rather than production code.

## Good tasks

- Create visual identity directions for FireKS.
- Explore logo treatments, palette systems, type mood, icons, stickers, banners, and section identities.
- Build a reference board for Art, Comics, Games, or the home page.
- Define a cohesive brand system before implementing a redesign.

## Output expectations

Produce a concise art-direction brief or image-generation prompt set with:

- Brand premise and audience.
- 2-4 visual routes with names.
- Palette roles, not just swatches.
- Typography mood and shape language.
- Asset applications: favicon, nav, hero, cards, thumbnails, social preview, section headers.
- Anti-references: what this identity must avoid.

For this project, preserve the playful pixel/creative-site feeling. Do not drift into corporate SaaS, generic cyberpunk, or bland portfolio minimalism unless explicitly requested.

## When generating images

Ask for or infer the format:

- Brand board.
- Logo exploration sheet.
- Website moodboard.
- Section identity sheet.
- Social preview/banner set.

Use image generation only for raster visual references. Implementation belongs in the code skills.
